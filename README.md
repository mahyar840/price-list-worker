# Price List Worker (مغز قضیه)

## معماری (نسخه‌ی جدید -- قالب گرافیکی ثابت + Overlay)

به‌جای این‌که هر بار یه گرافیک جدید تولید بشه، یه **قالب گرافیکی ثابت** (`assets/template-empty.png`) داریم که فقط یه بار ساخته و تایید شده. کد فقط اسم/رنگ/قیمت واقعی (از OCR) رو تو مختصات دقیق هر باکس، روی همون عکس ثابت می‌نویسه. این یعنی:
- گرافیک هیچ‌وقت عوض/خراب نمی‌شه (چون دیگه تولید نمی‌شه، فقط بارگذاری می‌شه)
- عددها همیشه دقیقاً از OCR واقعی میان، نه حدس

فونت و اندازه‌ی سطر **ثابته و هیچ‌وقت کوچیک/بزرگ نمی‌شه**؛ اگه یه دسته آیتم بیشتر از جای خالیش داشته باشه، مازادش حذف می‌شه (نه فونت‌ریز). تعداد حذف‌شده‌ها تو کپشن پیام تلگرام گزارش می‌شه تا بی‌خبر نمونی.

**محدودیت فعلی**: فقط ستون‌های شیائومی، سامسونگ و انکر (۱۶ دسته) نقشه‌برداری شدن. آیتم‌هایی که برندشون تو این سه ستون نیست (iPhone, Motorola, realme, ...) فعلاً OCR میشن ولی چون دسته‌ی تعریف‌شده ندارن، رد می‌شن و تو گزارش «uncategorized» می‌بینیشون. وقتی این نسخه رو تست کردی و اوکی بود، بخش راست تصویر (برندهای کوچیک) رو هم نقشه‌برداری و اضافه می‌کنم.
 
## مراحل دیپلوی (فقط از داشبورد کلود‌فلر، بدون CLI)

### ۱. ریختن روی گیت‌هاب
کل این پوشه (`src/`, `assets/`, `wrangler.toml`, `package.json`) رو تو یه ریپوی گیت‌هاب push کن.

### ۲. گرفتن لینک خام (raw) تصویر قالب
بعد از push، برو رو فایل `assets/template-empty.png` تو گیت‌هاب، دکمه‌ی **Raw** رو بزن، لینکش رو کپی کن (چیزی شبیه `https://raw.githubusercontent.com/USERNAME/REPO/main/assets/template-empty.png`).

### ۳. ساخت دو KV Namespace
داشبورد کلود‌فلر: **Workers & Pages → KV → Create a namespace**
- یکی به اسم `BOT_CONFIG`
- یکی به اسم `SESSIONS`

### ۴. ست‌کردن wrangler.toml
تو گیت‌هاب `wrangler.toml` رو ادیت کن:
- دو تا `REPLACE_WITH_KV_ID` رو با ID های واقعی (از مرحله ۳) عوض کن
- `TEMPLATE_URL` رو با لینکی که مرحله ۲ گرفتی عوض کن
Commit کن.

### ۵. وصل کردن ریپو به کلود‌فلر
**Workers & Pages → Create → Import a repository** → ریپو رو انتخاب کن → **Deploy**. از این به بعد هر push = دیپلوی خودکار.

### ۶. تعریف اولین بات
**Worker → KV → BOT_CONFIG → Add entry**
- Key: `bot:khazbox`
- Value:
```json
{ "telegramToken": "TOKEN_HERE", "defaultMargin": 20 }
```
(دیگه لازم نیست shopName/phone بدی -- تو خود قالب هست.)

### ۷. کلید Anthropic
**Worker → Settings → Variables and Secrets → Add** → Type: Secret → Name: `ANTHROPIC_API_KEY`

### ۸. وبهوک تلگرام
تو مرورگر باز کن:
```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<worker>.workers.dev/webhook/khazbox
```

## استفاده
عکس(های) لیست قیمت رو به بات بفرست → `/generate` بزن → عکس نهایی با گرافیک قالب و قیمت‌های واقعی برمی‌گرده. اگه چیزی حذف/رد شده باشه، تو کپشن پیام می‌بینی.

## اضافه کردن بات جدید
فقط مرحله ۶ و ۸ رو با یه `botId` جدید تکرار کن.
